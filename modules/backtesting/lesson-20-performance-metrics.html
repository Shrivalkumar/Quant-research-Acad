Understanding Performance Metrics

Interpret return, risk, path, trade, exposure, turnover, and concentration metrics with formulas, examples, and limitations.

Intuition first

Every metric compresses information—and therefore hides something

Total return compares endpoints; CAGR converts endpoint growth into a constant annual rate. Volatility summarizes dispersion of periodic returns. Sharpe divides average excess return by volatility, annualized under a convention. Maximum drawdown measures the worst peak-to-trough decline; duration measures time spent below a prior peak. Calmar divides CAGR by absolute max drawdown.

Trade metrics answer different questions. Win rate ignores win/loss size. Profit factor is gross wins divided by absolute gross losses. Expectancy combines probabilities and average payoffs. A portfolio can have good trade statistics but poor cash utilization, or good CAGR dominated by one open position absent from closed-trade tables.

Exposure measures how much capital or time is at risk. Turnover measures how much is traded; definitions vary. Cost drag should be measured by rerunning identical decisions with and without cost, not guessed from one trade. Best/worst years reveal concentration; removing the best year tests dependence but is not a prediction.

The harness uses daily equity returns for both tasks and √252 annualization. Task 1 may trade 15-minute bars, but its returns are summed within each day and equity compounds daily. Annualizing raw 15-minute returns separately would not match scoring.

Questions beginners actually ask

Clear answers before we add mathematics

Why is Sharpe not enough?

Sharpe compresses average excess return and volatility into one number. It can hide severe skew, long drawdowns, concentration in one year, uncertain estimates, and overfitting.

Why are trade metrics and portfolio metrics different?

Trade metrics usually examine closed round trips. Portfolio metrics include cash, overlapping positions, open holdings, varying exposure, and compounding through calendar time.

Follow the mechanism slowly

What happens first, second, third, and fourth

01

Build daily equity returns

Start from total close-of-day equity and compute chronological percentage changes. This aligns both assignment tasks to one metric frequency.

02

Measure reward and variability

Total return and CAGR summarize growth; volatility and Sharpe summarize dispersion and excess return under stated conventions.

03

Measure path pain

Drawdown depth and duration show the experience between endpoints. A smooth endpoint can hide a severe interim loss.

04

Add implementation diagnostics

Exposure, turnover, cost drag, years, trades, and concentration explain how the headline result was produced and where it may fail.

Deeper explanation

Sharpe is an estimate, not a property engraved on the strategy

Sharpe changes with the sample, frequency, risk-free convention, and return definition. Serial correlation and non-normal tails complicate the familiar annualization. Two reported Sharpes are comparable only when their underlying conventions and periods match.

A small difference such as 1.10 versus 1.18 may be sampling noise. Prefer a strategy whose economics, drawdown, turnover, and neighboring parameters are all understandable over one that wins by a tiny in-sample ratio.

Drawdown contains both depth and time

A 20% fall recovered in a week can be operationally different from the same fall lasting eighteen months. Maximum drawdown records only depth. Duration and time under water describe how long capital remains below its previous peak.

Drawdown is path-dependent: rearranging identical daily returns changes the maximum decline. It is also a historical observation, not a confidence bound. Hidden or live data can create a deeper and longer episode than anything in training.

Trade concentration and exposure complete the picture

A 50% CAGR generated by three enormous winners has different reliability from the same CAGR spread across many trades and years. Calculate largest-trade contributions and performance after removing the best year. Then ask whether those large gains match the hypothesized mechanism.

Low exposure can improve Sharpe by avoiding volatility, but it may leave results dependent on a few active windows. Report exposure beside return so the evaluator can see how intensively capital was used.

Worked walkthrough

Worked metric set

Equity rises from ₹100 to ₹121 over two years: CAGR = (121/100)1/2−1 = 10%. It peaks at ₹125 then falls to ₹100: drawdown = 100/125−1 = −20%; if CAGR remains 10%, Calmar = 0.10/0.20 = 0.50.

Daily mean return is 0.08%, daily SD 1%, risk-free 6% annual. Daily excess mean = 0.0008−0.06/252 = 0.0005619. Sharpe = 0.0005619/0.01×√252 = 0.892. A Task 2 Sharpe would use zero risk-free under this harness, yielding 1.270 for the same mean/SD.

Trades: four +5%, six −2%. Win rate 40%; expectancy +0.8%; profit factor = 20/12 = 1.67 before costs.

Implementation lens

Rebuilding harness-style metrics

r = equity.pct_change().dropna()
years = (equity.index[-1]-equity.index[0]).days/365.25
cagr = (equity.iloc[-1]/equity.iloc[0])**(1/years)-1
dd = equity/equity.cummax()-1
sharpe = (r.mean()-rf/252)/r.std()*np.sqrt(252)
calmar = cagr / abs(dd.min())

Educational pattern—adapt only after you can explain every line.

Why this matters for my H TO H Partners assignment

The scoring thresholds are necessary conditions, not proof of robustness. Quote the harness definitions. Task 1’s per-trade returns ignore carry/roll; Task 2 trade count includes only closed positions; neither should be forced to reconcile with portfolio CAGR.

Failure prevention

Common mistakes

  • Annualizing 15-minute returns while scoring daily equity
  • Comparing Sharpe values with different risk-free conventions
  • Treating maximum historical drawdown as a bound
  • Using win rate without payoff sizes
  • Calculating top-trade contribution from only winners without stating denominator
