Building Indicators Correctly

Calculate moving averages, momentum, ATR, volatility, highs, breakouts, and higher-timeframe features without information leakage.

⏱ 85 min● Concept + calculation + practice⌁ H TO H assignment linked
Learning objectives

By the end, you can…

  • Compute common indicators by hand and in pandas
  • Explain every indicator as a historical transformation
  • Use min_periods and lagging deliberately
  • Avoid incomplete higher-timeframe bars

Intuition first

An indicator summarizes history; it does not create information

A simple moving average equally weights the latest L observations. An exponential moving average gives recent observations more weight. Momentum compares today with an earlier price. Rolling volatility summarizes return dispersion. ATR averages true range, which includes gaps through the maximum of high−low, |high−previous close|, and |low−previous close|.

A breakout compares price with a prior rolling high or low. The word prior matters: if today’s high participates in the threshold, the condition may become mechanically harder or use information from inside the bar. A common pattern is high.rolling(L).max().shift(1).

Higher-timeframe features are dangerous. At 11:00, the current day’s final close is unknown. Resampling a complete historical CSV and forward-filling the daily close through that same day leaks the future. Use only completed higher-timeframe bars or update a clearly defined partial-bar feature.

Questions beginners actually ask

Clear answers before we add mathematics

Are indicators predictions?

No. They are summaries of information already observed. A moving average describes historical prices; whether it predicts a later return is a separate empirical question.

Why does shift(1) appear after a rolling high?

The rolling calculation otherwise includes the current bar. Shifting turns it into the high that was fully known before the current bar, which is necessary for a “break above the prior high” test.

Follow the mechanism slowly

What happens first, second, third, and fourth

01

Write the mathematical definition

Name the exact observations and inclusive endpoints. “Twenty-day high” is ambiguous until current-bar inclusion is stated.

02

Calculate only completed information

Trailing windows end at the current close. A prior breakout threshold often shifts the rolling extreme by one row.

03

Allow a real warm-up

Until enough observations exist, the indicator is undefined. Forcing a value with a very small minimum period changes the indicator.

04

Test predictive use separately

An indicator can be computed perfectly and have no useful expectancy. Compare subsequent outcomes after timing and costs rather than trusting the chart.

Deeper explanation

Moving averages and momentum encode memory differently

A 20-period simple average uses every included close with equal weight. An exponential average gives recent closes more influence but never completely forgets older history. L-period momentum uses only the endpoint ratio, so the path between endpoints is ignored. Two paths can have identical momentum and very different volatility.

These differences are not cosmetic. They imply different reaction speed, turnover, and failure modes. Choose an indicator because its memory matches the hypothesis, then test neighboring memories rather than assuming a popular number is special.

Volatility normalization changes the question

Dividing momentum by volatility asks for return relative to recent variability. It may prefer a steady 12% rise over a volatile 20% rise. The normalized score can become unstable when estimated volatility is very small, so floors, caps, and minimum observations matter.

Normalization also adds estimation error and a parameter window. It should be treated as a new hypothesis, not a harmless unit conversion. Compare raw and normalized features through an ablation and inspect how selections and sector exposures change.

Worked walkthrough

ATR by hand

Previous close = 100; today high = 108, low = 103. The three ranges are 5, 8, and 3. True range = max(5,8,3)=8 because the overnight gap matters. If prior two true ranges were 4 and 6, a three-day simple ATR is (4+6+8)/3 = 6.

Implementation lens

Causal indicators

sma50 = close.rolling(50, min_periods=50).mean()
mom63 = close / close.shift(63) - 1
ret = close.pct_change(fill_method=None)
vol20 = ret.rolling(20, min_periods=20).std()
prior_high = high.rolling(20, min_periods=20).max().shift(1)

Educational pattern—adapt only after you can explain every line.

Assignment connection

Why this matters for my H TO H Partners assignment

Task 1 receives the full bar history and is tested at truncated points. Task 2 has young listings. Return flat/no order until enough observations exist; do not lower min_periods merely to force early trades unless that is an explicit, tested design choice.

Failure prevention

Common mistakes

  • Using a centered moving average
  • Comparing close with a rolling high that includes an unintended current bar
  • Treating NaN as a sell signal without design
  • Forward-filling a completed-day feature into its own incomplete day
Retrieval practice

  2. It includes gaps from prior close
