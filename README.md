# Quant Research Academy

A 42-page offline HTML/CSS course built around the supplied H TO H Partners candidate pack.

## Open

Double-click `index.html`. No server, JavaScript, package installation, or network connection is required. External links on the references page are optional further reading.

## Scope

- 28 lessons in 6 modules
- Assignment deconstruction and audited harness guide
- Task 1 and Task 2 research workflows without submission-ready strategies
- Five-day roadmap, quizzes, 30-question mock assessment
- Formula and Python sheets, 100+ term glossary
- Mistakes gallery, research journal, interview practice

## Integrity

Candidate-pack originals were inspected read-only. The academy does not contain completed assignment strategies, fabricated performance, or private data. Template baseline numbers are clearly labeled as measured harness outputs.
