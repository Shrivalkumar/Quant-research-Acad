Task 1 order of operations

bar i closepositions() chooses targetbar i+1 opentarget becomes actual positionwithin barposition earns close/open moveday endsum bar contributions + daily cash

The actual array is pos[1:] = want[:-1]; then pos[:200] = 0. The first nonzero actual position can therefore only appear at index 200 or later. On every bar the contribution includes the prior position’s gap return, the current position’s intrabar return, and cost on the change. On a new day only, the prior overnight position pays signed carry; a short receives it. If the previous date is an expiry, the absolute prior position also pays a two-side roll cost. Finally, every day—including invested days—adds 6%/252 cash return because the model treats margin capital as earning liquid-fund interest.

Subtle point: daily excludes cash; task1_stats builds equity from 1 + daily + 0.06/252. Per-trade returns ignore carry and rolls, so their average will not reconcile exactly to portfolio CAGR.

Task 2 order of operations

  1. After close t — orders() sees history only through t and today’s close-valued portfolio.
  2. Open t+1 — market sells execute first.
  3. Then buys — listed order matters; each is capped at 15% and cash available.
  4. During t+1 — buy stops require high > trigger, not ≥, and fill at max(open, trigger).
  5. After buys — stop sells can trigger, but never on a position bought that day.
  6. Close t+1 — positions use latest forward-filled close for valuation; new orders are requested.
Cash nuance: proceeds from a stop sell occur after the buy loop, so they cannot finance that day’s buys. Unfilled orders lapse after one day.

Metric definitions in this harness

Daily equity returns feed all portfolio metrics. Years are calendar days divided by 365.25. CAGR uses first and last equity values. Sharpe is (mean daily return − rf/252) / daily standard deviation × √252; rf is 6% for Task 1 and zero for Task 2. Year-wise returns concatenate the first equity point with calendar year-end observations before taking percentage changes. Turnover definitions differ by task: Task 1 sums absolute position changes per year; Task 2 divides total traded notional by mean equity and years.

Verified ambiguities and boundaries

  • The pasted brief says “approximately 585” stocks; the README, symbols file, and CSV all establish 555.
  • The evaluation end is configured as 30 Jun 2024, but the last observed trading date is Friday 28 Jun 2024.
  • The README’s expiry calendar is an assignment approximation. Current live NSE contract rules may differ; use the supplied expiry CSV for the backtest.
  • The harness does not force liquidation on the final day. Open Task 2 holdings remain in terminal equity but are absent from closed-trade statistics.
  • Task 1’s random truncation check samples four cut points. Passing it is helpful but not proof that every feature is causal.
