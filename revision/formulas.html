Formula Cheat Sheet

Notation, assumptions, and the exact places where an innocent-looking formula can become a timing bug.

Simple return

rₜ = Pₜ / Pₜ₋₁ − 1

Use adjusted prices when the economic claim requires corporate-action continuity.

Log return

gₜ = ln(Pₜ / Pₜ₋₁)

Log returns add through time; portfolio aggregation still uses weights and simple returns.

Compound wealth

Wₜ = W₀ ∏(1 + rᵢ)

Never add multi-period percentage returns unless using log returns appropriately.

CAGR

(Wₜ / W₀)^(1 / years) − 1

A constant annual rate matching endpoints; hides path and drawdown.

Annualized volatility

σ_ann = σ_daily √252

Assumes an annualization convention; autocorrelation complicates interpretation.

Sharpe

(mean(r_daily) − r_f/252) / sd(r_daily) × √252

The harness uses daily equity returns and task-specific idle-cash rates.

Drawdown

DDₜ = Wₜ / maxₛ≤ₜ Wₛ − 1

Maximum drawdown is the minimum of this series.

Futures P&L

position × notional × price return

The Task 1 harness models 1× capital fractions, not exchange lots and margin calls.

Portfolio return

r_p = Σ wᵢ rᵢ + cash return − costs

Weights must correspond to holdings during the return interval.

Transaction cost

cost = traded notional × rate per side

A +1 to −1 Task 1 flip trades two sides.

Momentum

M_L = Pₜ/Pₜ₋L − 1

Rank only after historical eligibility is determined.

Rolling volatility

σₜ,L = std(rₜ₋L+1…rₜ)

Set minimum observations and never use centered windows.

Volatility sizing

weight ∝ target volatility / estimated volatility

Cap weights; estimates can jump or become unstable.

Turnover

Σ |weight changes| or traded notional / equity

Definitions vary. Quote the harness definition you used.
