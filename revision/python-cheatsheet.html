Pandas & NumPy Cheat Sheet

Short, causal patterns for market-data research. These examples are educational building blocks, not submission strategies.

Load & sort

df = pd.read_csv(path, parse_dates=['date'])
df = df.sort_values(['symbol', 'date'])

Causal lag

yesterday = prices.shift(1)
# shift rows, never columns, for time lag

Rolling by symbol

df['mom_63'] = (
  df.groupby('symbol')['close']
    .pct_change(63, fill_method=None)
)

Wide point-in-time ranks

eligible_score = score.where(eligible)
ranks = eligible_score.rank(axis=1, ascending=False, method='first')

Safe return

ret = close.pct_change(fill_method=None)
# do not silently fill missing prices

Resample OHLC

daily = bars.resample('1D').agg({
 'open':'first','high':'max','low':'min','close':'last'
}).dropna(subset=['open'])

Rolling liquidity

traded_value = close * volume
liq = traded_value.rolling(60, min_periods=40).median()

Diagnostics

summary = returns.describe(percentiles=[.01,.05,.5,.95,.99])
worst = returns.nsmallest(10)

Leakage guardrails

  • Sort before rolling.
  • Group by symbol before a long-format lag.
  • Use axis=1 for cross-sectional ranks and the default row axis for time shifts.
  • Do not use bfill() on features: it imports future observations.
  • A higher-timeframe feature is available only after that higher-timeframe bar closes.
  • Keep plotting in a separate research environment; submitted functions should remain deterministic and fast.
