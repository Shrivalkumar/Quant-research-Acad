Twenty-five mixed questions. Answer on paper first; native disclosures hide explanations until you choose to reveal them.

A. Financial markets quiz

Retrieval practice

Exercises

1. The best ask is ₹250 for 20 shares. You market-buy 100 shares. What is guaranteed?

  1. All 100 fill at ₹250
  2. At most 20 can fill at ₹250 before other ask levels matter
  3. The order cannot fill
  4. The spread becomes zero
Reveal explanation

Answer: B. Only displayed quantity at that price is available; the remainder may walk up the book.

2. Why delay a close-based signal to the next open?

  1. To lower returns
  2. Because the full close was unavailable before that bar ended
  3. Because markets forbid close trades
  4. Only to add costs
Reveal explanation

Answer: B. The lag enforces causal information timing.

3. In Task 1, +1 means…

  1. One exchange contract
  2. 1× capital modeled long exposure
  3. Unlimited leverage
  4. All cash spent on index shares
Reveal explanation

Answer: B. The harness normalizes notional to capital.

4. Harness carry on an overnight short is…

  1. Paid by the short
  2. Received by the short
  3. Zero
  4. Equal to the roll cost
Reveal explanation

Answer: B. The code subtracts position×carry; negative position makes a credit.

5. Ten equal-weight sector peers primarily reduce…

  1. All risk
  2. Name-specific risk more than shared sector risk
  3. Gap risk completely
  4. Costs
Reveal explanation

Answer: B. Common-factor exposure remains.

B. Quantitative mathematics quiz

Retrieval practice

Exercises

1. +20% then −20% produces…

  1. 0%
  2. −4%
  3. +4%
  4. −20%
Reveal explanation

Answer: B. 1.2×0.8−1 = −4%.

2. Correlation between a signal and returns proves…

  1. Causation
  2. Only measured co-movement in that sample
  3. Profit after costs
  4. Persistence
Reveal explanation

Answer: B. Mechanism and validation are still needed.

3. Task 1 Sharpe subtracts…

  1. Zero
  2. 6%/252 from daily returns
  3. 1.3%/252 only
  4. Transaction costs twice
Reveal explanation

Answer: B. The harness compares with idle cash.

4. A −20% drawdown needs what gain to recover?

  1. 20%
  2. 25%
  3. 40%
  4. 10%
Reveal explanation

Answer: B. 0.8×1.25 = 1.

5. Why can a stop lose more than its threshold distance?

  1. Compounding only
  2. Overnight gaps and fill rules
  3. Because stops add dividends
  4. It cannot
Reveal explanation

Answer: B. Execution can occur beyond the trigger.

C. Backtesting and research quiz

Retrieval practice

Exercises

1. Which should be debugged first?

  1. Sharpe formatting
  2. Information and fill timeline
  3. Report typography
  4. Annualization
Reveal explanation

Answer: B. Causality errors invalidate downstream metrics.

2. A daily liquidity filter on surviving symbols removes survivor bias?

  1. Yes
  2. No
  3. Only with 60 days
  4. Only if volume adjusted
Reveal explanation

Answer: B. Excluded historical failures are still unavailable.

3. Why is a sharp single best parameter cell suspicious?

  1. It proves precision
  2. It may be noise or optimization sensitivity
  3. It lowers costs
  4. It increases sample size
Reveal explanation

Answer: B. Robust mechanisms usually tolerate nearby settings better than a knife-edge rule.

4. A robust parameter surface usually looks like…

  1. One isolated spike
  2. A neighborhood of acceptable results
  3. All NaNs
  4. Maximum turnover
Reveal explanation

Answer: B. Plateaus reduce dependence on precise coordinates.

5. “Keep” means…

  1. True forever
  2. Worth further testing under the stated evidence
  3. Deploy unlimited capital
  4. No failure mode
Reveal explanation

Answer: B. Research conclusions remain conditional.

D. Task 1 preparation quiz

Retrieval practice

Exercises

1. Which exists only after execution?

  1. Feature
  2. Score
  3. Target
  4. Actual holding
Reveal explanation

Answer: D. A target is an intention; a fill creates the holding.

2. A slower signal generally trades off…

  1. Less lag for more turnover
  2. More lag for less turnover
  3. No costs for leverage
  4. Higher accuracy guaranteed
Reveal explanation

Answer: B. Smoothing reduces churn but reacts later.

3. Why does operation order matter?

  1. Only speed
  2. Cash and eligibility depend on earlier events
  3. It changes CSV names
  4. It never matters
Reveal explanation

Answer: B. Sell/buy/stop sequence changes feasible holdings.

4. How many Task 2 stocks are actually supplied?

  1. 585
  2. 555
  3. 550
  4. 790
Reveal explanation

Answer: B. README, symbols, and CSV agree on 555.

5. Why test extra fill delay?

  1. To change the hypothesis
  2. To measure signal decay and implementation fragility
  3. To increase sample size
  4. To remove costs
Reveal explanation

Answer: B. A robust signal should not vanish instantly unless its mechanism predicts that.

E. Task 2 preparation quiz

Retrieval practice

Exercises

1. A stock can rank first with negative momentum when…

  1. Impossible
  2. All stocks are negative and it fell least
  3. Volume is zero
  4. It is Nifty
Reveal explanation

Answer: B. Cross-sectional rank is relative.

2. Why can order list order matter?

  1. Python is random
  2. Stop buys fill until slots/cash are exhausted in listed order
  3. Prices depend on alphabet
  4. Sells never execute
Reveal explanation

Answer: B. The harness processes buys sequentially.

3. Which leaks most directly?

  1. Trailing mean
  2. Centered rolling mean
  3. shift(1)
  4. Next-open fill
Reveal explanation

Answer: B. Centered windows include later observations.

4. Task 2 stop buy triggers when…

  1. high ≥ trigger
  2. high > trigger
  3. close > trigger only
  4. open = trigger
Reveal explanation

Answer: B. The harness uses a strict greater-than test.

5. Historical liquidity eligibility should use…

  1. Future October 2026 volume
  2. Trailing data available by decision close
  3. Full-sample median
  4. Next-day volume
Reveal explanation

Answer: B. Eligibility must be point-in-time.
