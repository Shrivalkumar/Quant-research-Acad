Retrieval practice

Exercises

1. A close-t feature is used to earn open-to-close t. Primary error?

  1. Survivorship
  2. Look-ahead / timing
  3. Dividend adjustment
  4. Capacity
Reveal explanation

Answer: B. The close was unavailable at the open.

2. Task 1 flips +1 to −1. Cost sides charged?

  1. 0
  2. 1
  3. 2
  4. 4
Reveal explanation

Answer: C. Absolute position change is 2.

3. ₹100 falls 20%. Gain needed to recover?

  1. 20%
  2. 25%
  3. 40%
  4. 80%
Reveal explanation

Answer: B. ₹80×1.25=₹100.

4. Seven Task 2 names at 15% request…

  1. 85%
  2. 100%
  3. 105%
  4. 115%
Reveal explanation

Answer: C. 7×15%=105%.

5. A buy stop trigger ₹100; open ₹106; high ₹108. Fill?

  1. ₹100
  2. ₹106
  3. ₹108
  4. None
Reveal explanation

Answer: B. max(open,trigger).

6. Cross-sectional rank per date in date×symbol DataFrame uses…

  1. axis 0
  2. axis 1
  3. centered rolling
  4. bfill
Reveal explanation

Answer: B. Compare columns within each row.

7. A flat Task 1 strategy earns…

  1. 0
  2. Modeled cash 6%/year
  3. Dividend only
  4. Carry only
Reveal explanation

Answer: B. Cash is credited daily.

8. Daily liquidity filter fully fixes survivor bias?

  1. Yes
  2. No
  3. Only with 60 days
  4. Only for top 10
Reveal explanation

Answer: B. Missing failed names remain absent.

9. Best evidence of robustness?

  1. One Sharpe 2.5 cell
  2. Stable neighboring settings and stresses
  3. Maximum parameters
  4. Highest turnover
Reveal explanation

Answer: B. A plateau is less coordinate-dependent.

10. Log returns are useful because they…

  1. Guarantee profit
  2. Add through time
  3. Equal simple returns
  4. Remove costs
Reveal explanation

Answer: B. Log price ratios sum.

11. The Task 2 order sequence begins with…

  1. Stop sells
  2. Market sells
  3. Buys
  4. Metrics
Reveal explanation

Answer: B. Market sells execute at open first.

12. A same-day Task 2 stop sell can close a newly bought position?

  1. Yes
  2. No
  3. Only if gap
  4. Only if Nifty
Reveal explanation

Answer: B. The harness requires position entry index < current index.

13. Task 1 Sharpe risk-free convention?

  1. 0
  2. 6% annual
  3. 1.3%
  4. Nifty return
Reveal explanation

Answer: B. Idle cash is the comparison.

14. Centered rolling windows are invalid because…

  1. They are slow
  2. They include future rows
  3. They ignore mean
  4. They use costs
Reveal explanation

Answer: B. The centered value uses later observations.

15. Win rate 40% can be profitable?

  1. Never
  2. Yes, with larger wins and sufficient cost margin
  3. Only with shorting
  4. Only daily
Reveal explanation

Answer: B. Expectancy depends on payoff size.

16. A rank-1 stock can have negative absolute momentum?

  1. No
  2. Yes, if peers fell more
  3. Only after split
  4. Only with volume
Reveal explanation

Answer: B. Relative and absolute differ.

17. Margin is best described as…

  1. Futures purchase price
  2. Collateral for exposure
  3. Dividend
  4. Transaction cost
Reveal explanation

Answer: B. Notional drives P&L.

18. A roll cost can occur with unchanged +1 position?

  1. No
  2. Yes
  3. Only flat
  4. Only hidden
Reveal explanation

Answer: B. The contract changes even if direction does not.

19. Task 1 bar labels represent…

  1. Bar end
  2. Bar start
  3. Settlement date
  4. UTC close
Reveal explanation

Answer: B. README specifies IST bar start.

20. The stock CSV contains how many symbols?

  1. 585
  2. 555
  3. 790
  4. 400,949
Reveal explanation

Answer: B. Exactly 555.

21. A full-sample z-score used in 2022 leaks…

  1. Only 2021
  2. Future mean/variance
  3. No information
  4. Transaction costs
Reveal explanation

Answer: B. Scaling includes later observations.

22. What should precede a full backtest?

  1. Report
  2. Tiny controlled accounting test
  3. Hidden data
  4. Maximum grid
Reveal explanation

Answer: B. Correctness before performance.

23. Why can top-10 trade contribution exceed 100%?

  1. Impossible
  2. Other trades net negative
  3. CAGR
  4. Cash interest
Reveal explanation

Answer: B. Winners can exceed net after losers.

24. A holdout tuned repeatedly becomes…

  1. More independent
  2. Training-like data
  3. A live exchange
  4. A benchmark only
Reveal explanation

Answer: B. Feedback consumes independence.

25. A 3×3 sensitivity grid should…

  1. Change logic per cell
  2. Hold all but two parameters fixed
  3. Report winner only
  4. Use hidden data
Reveal explanation

Answer: B. Comparable cells isolate parameters.

26. Task 2 unfilled orders…

  1. Persist forever
  2. Lapse after next trading day
  3. Fill at close
  4. Become limit orders
Reveal explanation

Answer: B. Orders are next-day only.

27. Why might trade P&L not reconcile with portfolio CAGR?

  1. Always bug
  2. Cash, open trades, exposure, compounding, carry/cost details
  3. Because dates invalid
  4. Because price uses INR
Reveal explanation

Answer: B. They are different accounting objects.

28. Best live-debug dataset?

  1. All rows
  2. Small labeled synthetic case
  3. Hidden data
  4. No data
Reveal explanation

Answer: B. Alignment becomes inspectable.

29. A failed experiment should record…

  1. Plausible invented results
  2. Actual settings, numbers, and interpretation
  3. Only conclusion
  4. No dates or ID
Reveal explanation

Answer: B. Contemporaneous evidence is required.

30. Most credible claim after passing public thresholds?

  1. Guaranteed hidden success
  2. Meets measured conditions on this sample; robustness remains uncertain
  3. No drawdown ever
  4. True alpha
Reveal explanation

Answer: B. Historical thresholds do not prove future persistence.

Scoring guide

26–30: ready for a timed walkthrough rehearsal. 21–25: revisit the explanation behind every miss. 15–20: repeat Modules 2, 3, and 5 before implementation. Below 15: return to the five-day plan and rebuild the foundations in order. This score is diagnostic, not predictive of selection.
