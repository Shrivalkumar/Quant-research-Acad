Five-Day Quant Research Preparation Roadmap

A demanding but realistic sequence. “Essential” means needed to attempt the assignment; advanced material can wait until the core pipeline is correct.

Day 1

Financial foundations & futures

6–7 hours

Study
Lessons 1–8; then 24
Practice
Trace one stock trade; calculate a futures P&L; inspect every pack file
Exit test
Explain spot vs futures, OHLC bars, next-open execution, carry, and rolls
Day 2

Statistics, Python & Task 1 foundations

7–8 hours

Study
Lessons 9–16, 19–20, 25
Practice
Rebuild return/Sharpe/drawdown on synthetic data; write micro timing tests
Exit test
Predict each Task 1 accounting contribution before running code
Day 3

Momentum & portfolio construction

7–8 hours

Study
Lessons 17–18, 21, 26
Practice
Create point-in-time ranks on synthetic multi-stock data; simulate caps and cash
Exit test
Explain universe bias, ranking, turnover, stop fills, and concentration
Day 4

Research discipline

7–8 hours

Study
Lessons 22–23; mistakes gallery
Practice
Pre-register a 3×3 grid; run delays/costs; log a genuine rejected idea
Exit test
Separate a robust plateau from a lucky cell and narrate failure honestly
Day 5

Submission & live defense

6–7 hours

Study
Lessons 27–28; mock assessment
Practice
Clean-room run; compress report; rehearse 20 questions and 5 code changes
Exit test
Modify one rule, sanity-check it, and explain results without hand-waving

Triage rules

Essential

Timing, fills, costs, returns, drawdown, Sharpe, point-in-time features, universe bias, harness interfaces, micro-tests.

Important

Parameter stability, regime diagnostics, attribution, report compression, code walkthrough fluency.

Optional if time remains

Purged validation, advanced statistical tests, elaborate risk models, or visualization polish beyond decision-useful charts.

Studying cannot guarantee passing. A smaller research pipeline you truly understand is stronger preparation than many complex ideas you cannot audit.
