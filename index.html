How to use this course

Read slowly. Translate every term.

This edition assumes no trading vocabulary. Do not move on simply because a paragraph is finished.

01

Learn the words first

Each lesson starts with a short vocabulary shelf. Say each definition in ordinary language before reading the lecture.

02

Follow the rupees

Recalculate the worked example on paper. If the cash, position, or return cannot be traced, reread before coding.

03

Explain without jargon

Use the checkpoint to teach the idea aloud as if the listener has never seen a market before.

Learning path

Build the mental model in order

The sequence is deliberate: execution before indicators, accounting before metrics, research design before optimization.

Academic integrity boundary

This academy teaches the craft. It does not write the submission.

Examples use synthetic numbers or clearly labeled, measured template outputs. No page contains a submission-ready Task 1 or Task 2 strategy, fabricated failed experiments, or invented performance. Your job is to form, test, and defend your own hypotheses.
